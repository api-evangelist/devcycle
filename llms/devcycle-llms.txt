# DevCycle

> DevCycle is an OpenFeature-native feature flag and feature management platform (a Dynatrace company). It provides a Management API for administering projects, environments, features, variables, variations, and audiences, and a Bucketing API for server-side flag evaluation, backed by client and server SDKs across all major languages, a CLI, and an official MCP server for AI coding agents.

## APIs
- [Management API docs](https://docs.devcycle.com/management-api/): OAuth2 client_credentials, base https://api.devcycle.com/v1
- [Bucketing API docs](https://docs.devcycle.com/bucketing-api/): SDK-key bearer auth, base https://bucketing-api.devcycle.com/

## Specs
- [Management API OpenAPI](https://api.devcycle.com/openapi.json): OpenAPI 3.0.0, 103 operations
- [Bucketing API OpenAPI](https://docs.devcycle.com/redocusaurus/bucketing-api.yaml): OpenAPI 3.1.0
